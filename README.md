# MARÉVYS PARIS — RC23 爱情探索与对话式解读

English / Français / 简体中文

本版沿用 MARÉVYS 品牌，新增爱情专区、首页快捷问题、主题牌阵与塔罗／星盘连续对话。所有解读页面采用米黄色背景，墨绿用于按钮。会员页展示 Free／Plus／Atelier 的拟定权益；尚未开放付费订阅，不模拟付款或会员开通。手记继续保存在当前浏览器。

设计取舍、参考网站调研与开通会员所需条件见 [RC23 体验说明](docs/RC23_EXPERIENCE_REVIEW.md)；新牌组的覆盖范围与素材来源见 [牌组说明](assets/decks/README.md)。

## 本版功能

- 爱情、工作、选择、今日、月度与季节等主题入口，使用服务器定义并固定的专用牌位。自由编辑问题采用通用模式，避免问题与主题错配。
- 保留原创和经典两套牌组，新增可爱、童话、写实、圣诞风格；新系列采用 22 张大牌插画与 56 张装饰数字／宫廷牌，会员开放前可以预览。圣诞系列计划于 11 月 15 日至 1 月 7 日开放选用。
- 完整 78 张塔罗牌：一张、三张、五张牌阵；抽牌前确定问题、背景、关注期限和是否使用逆位。
- 服务器使用安全随机数洗牌；盲选、自动选牌和逐张翻牌共享同一副已洗好的牌。生产环境通过 Redis 固定牌阵，重复或并发请求不能换牌。
- 深入解读结合牌、正逆位、固定牌位、相关资料摘要和用户背景，输出综合分析、牌间关系、不确定性与行动建议。
- 原牌阵可追问；每次会话只能补一张澄清牌。补牌从原牌堆取出，不覆盖或替换原牌。
- 本命星盘由 Astronomy Engine 计算，采用回归黄道、地心位置和整宫制；AI 仅解释已计算的事实。
- 出生时间未知时展示当天可能范围，不展示上升、宫位或精确相位。城市搜索支持全球地名，并根据所选城市处理坐标、IANA 时区与夏令时。
- 手记保存在当前浏览器，可查看先前记录，不需要会员或登录。

## 当前就绪状态

截至 2026-10-22，RC23 包含可运行的前后端改造及自动验证。自动测试通过隔离的 AI／Redis 响应验证契约，不代表真实供应商或支付账户已连接。现有 GitHub → Vercel 发布链路保留；本次改动的实际部署结果以提交状态及交付说明为准。

真实订阅需要连接正确的托管项目和商户账户，再完成可信身份、服务器会员权限、付款回调和取消订阅测试。当前版本不会通过浏览器开关授予付费权限。

| 能力 | 本地未配置凭据 | 生产需要 |
| --- | --- | --- |
| 页面、资料卡、手记 | 可用 | 静态资源部署 |

## 本地运行

使用 Node.js 22。依赖固定在 package-lock.json。

```sh
npm ci
npm run build:web
npm run dev
```

访问 http://localhost:4173 。RC21 新体验需要 HTTP 服务；直接打开旧离线 index.html 或完整嵌入 HTML 不代表本版在线体验。

需要启用 AI 时，将 .env.example 复制为 .env.local，在本机私下填写凭据，然后运行：

```sh
npm run check:config
npm test
```

配置检查只验证变量存在和格式，不打印密钥，不调用供应商。测试不会产生 OpenAI 调用费用。真实服务验收见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 资料与解读边界

server/tarot-cards.json 包含 78 张牌的中／法／英原创释义摘要及出处；server/tarot-references.json 包含方法摘要、来源目录、PDF 页码和资料范围说明。当前状态为 curated_draft_not_professionally_reviewed：经过整理但尚未由专业同事进行案例盲评。

线上检索使用整理后的摘要和方法，不会每次发送整本书，也不等于已对模型完成训练。九份文件已登记来源；可提取程度、所属体系和完成审读程度不同。《神奇之门》属于奇门遁甲，不进入塔罗牌义检索。原始 PDF、全文提取及私有工作文件不进入公共网站资源。

默认牌组为 MARÉVYS 原创插画；可选的 Heritage 使用历史 RWS 1909 图像，其署名和来源见 THIRD_PARTY_LICENSES/RWS_1909_ATTRIBUTION.md 及对应 provenance 文件。新系列素材的具体范围见 assets/decks/README.md。解读属于象征性探索，计算精度或书籍出处不构成预测准确性的验证。

## 数据保存

- 当前塔罗流程使用 sessionStorage，刷新同一标签页可继续；关闭标签页后的会话保留由浏览器决定。
- 点击保存后的解读、出生信息和手记使用 localStorage，最多保留 100 条新版本记录。清除浏览器数据会删除记录，没有跨设备同步。
- 生产 Redis 保存加密的塔罗牌堆、问题、背景和会话状态，最长 7 天，不保存 AI 正文。限额使用经过 HMAC 处理的 IP 标识，不写入原始 IP。
- AI 请求使用 store:false；这不等于供应商零数据保留承诺。应用不会主动将问题或出生信息写入日志。
- 会话令牌可以访问本次抽牌，应作为私有内容处理，不能粘贴到公开日志或链接。
