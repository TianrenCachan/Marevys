## 如何完整预览

直接打开项目上一级的 `MAREVYS_PARIS_RC19_Complete_Embedded.html`，或在完整项目中打开 `index.html`。两份入口均内嵌全部样式、脚本、三语文案、105 项视觉资源与符文字体，不需要安装依赖、启动服务器或联网加载图片；请使用允许 JavaScript 的 Chrome、Edge 或 Safari。

右上角 `EN / FR / 中文` 可随时切换语言。左上角 MARÉVYS 标志始终返回主页。

## RC19 的核心体验

首页只保留一个编号为 `01 / CHOOSE YOUR READING` 的阅读入口，不再拆成两个重复模块，也不保留无意义的过渡条带。符文、塔罗与易经在同一紧凑区块中明确各自所长、时间范围和使用方式：首页案例只展示问题与解读价值，不提前透露产品名称或套组。

三套阅读共享一条连续动线：

1. 提出一个真实问题；
2. 系统自动进入固定方法：符文一枚、塔罗三张、易经六爻；塔罗先带着原问题完成一次五秒冥想；
3. 盲抽符文／翻开塔罗／六次投币起卦；
4. 先阅读与问题直接相关的完整解读；
5. 点击唯一的继续按钮，进入私人能量匹配并揭示四件器物；
6. 按四个连续动作完成日常仪式；
7. 保存个人记录，并预览 CERCLE 会员档案入口。

## 三种体系与时间范围

| 体系 | 主要用途 | RC19 时间范围 | 抽取方式 |
| --- | --- | --- | --- |
| 符文 | 聚焦一项优先事项、助力、核心阻力与可观察的风险信号 | 未来 7 天 | 从 24 个 Elder Futhark 字符中盲抽一枚；不随机设置正逆位 |
| 塔罗 | 展开一周的主调、机会与阻力／风险 | 未来 7 天 | 从 22 张大阿尔克那中盲选三张，按 `WEEKLY THEME`、`OPPORTUNITY`、`FRICTION / RISK` 依次 3D 翻面；不使用逆位 |
| 易经 | 判断较大变化中的当前结构、转折条件与发展方向 | 3–12 个月 | 三枚虚拟硬币投掷六次，爻自下而上；6 与 9 为动爻 |

七日与 3–12 个月是 MARÉVYS 的产品化解读框架，不冒充古代体系的固定预测期限。易经的之卦表示条件成立时可能形成的变化方向，不是注定的终局、事件或日期。

## 解读输出与 AI

离线预览可完整运行。规则引擎会把访客的问题、引导方向、抽取符号、位置与变化关系组织成具体叙事，而不是表格式关键词堆叠。

- 符文：七日趋势、当前助力、核心阻力、风险信号、条件分支、48 小时行动与七日复盘；
- 塔罗：`WEEKLY THEME`、`OPPORTUNITY`、`FRICTION / RISK` 三个位置的独立连接、综合判断、现实行动与七日复盘；
- 易经：3–12 个月的结构与时机、本卦、动爻层级、作为条件方向的之卦、阶段性行动与一个月复核点。

配置 `window.MAREVYS_AI_ENDPOINT` 后，三套体系可把结构化 payload 发送至同一个服务端接口。在线请求失败、超时或响应不符合严格 schema 时，网页自动回退到本地解读，不中断私人匹配与仪式。

AI 只生成结构化解读文字和两个受控能量标签，不能返回 HTML、图片、SKU、价格、疗效或产品事实。通过校验的标签仅参与八条能量路径的排序；每条路径的四件器物、顺序、理由和仪式均由 `src/experience-data.js` 确定。接口契约见 `AI_INTEGRATION.md`。

## 产品最终揭示

产品不出现在首页案例，也不混入解读正文。完整解读结束后，访客点击一个主要按钮进入 `05 · THE REVEAL`，先看到与结果对应的独立套组照片，再看到四件器物及其 `当前状态 → 目标状态`、感官机制和仪式角色。下一页把四件器物串成一个有开始、有转换、有锚点、有结束的现实仪式。

当前仍为概念商业原型：没有价格、库存、购物车、支付或配送。完整解读不以购买为条件；产品承担感官提示与行动锚点，不承诺改变外部事件。

## 视觉与图片规则

RC19 内嵌 105 项视觉资源：104 项内容资产与 1 项透明 Logo。24 枚盲选符文石各自使用一张独立生成的真实玄武岩照片；其他内容图片也各自只承担一个语义用途，不在首页、解读、产品和仪式之间重复，也不把一张大图裁成多个商品图。

其中 22 张大阿尔克那牌面是 22 个独立文件：`assets/tarot-00.webp` 至 `assets/tarot-21.webp`。每张牌拥有独立构图，不是从一张牌组总图裁切；抽牌和翻牌都使用 `assets/tarot-card-back-arcana22.webp`，商品书签中的 ARCANA 22 也沿用同一正式牌背。符文盲选使用四种真透明玄武岩切图，不再用 CSS 圆石；符文正文由 CSS 构成清晰、有边缘厚度和内凹刻字的石板，而不是把横向照片拉伸成背景。塔罗采用细腻深蓝金边卡纸，易经采用重新制作的室内东方静物与宣纸材质。

12 张商品主图全部为 1024 × 1280 的 4:5 成品画幅；匹配页另有 12 张独立的 4:5 器物识别图，让读者先看清每个名称对应什么；仪式页再使用 12 张不同的 2:3 竖向书签图。保存页使用独立的 RETURN 01 摊开笔记本画面，把解读摘要、日期与用户笔记直接组织在纸面上。

品牌处理继续遵守已确认规则：

| 对象 | 品牌处理 |
| --- | --- |
| 符文石、茶碗、能量石、塔罗卡牌、易经器物、仪式布 | 不放 Logo |
| 香水 | 经典五号香水式克制矩形标签层级，保留小型 MARÉVYS 标志 |
| 蜡烛 | 与香水协调的小型纸质标签 |
| 手记 | 下边缘小型、低对比压印 |
| 其他可自然承载品牌的器物 | 仅使用小型、物理可信的刻印或标签 |
| 首页 | 不使用大型居中 Logo；导航标志返回主页 |

资源尺寸、字节数与 SHA-256 见 `ASSET_MANIFEST.json`；生成与编辑说明见 `IMAGE_PROMPTS.json`。

## 首页信息架构

- Hero：只保留居中单行主标题与一个高对比度主要开始按钮，信息说明紧接在下一板块；
- 01：同一模块内比较符文、塔罗与易经的优势、时间范围和示例；
- 02：器物系列总览；
- 03：四件器物如何进入现实生活；
- 04：需要加入／登录 CERCLE 才能打开的过往解读档案；
- 05：带独立配图的品牌主张，以及 READ / TRANSLATE / EMBODY 三步方法；
- FAQ：解释免费预览、保存位置、概念产品与阅读边界。

## 会员档案与数据真实性

第一份阅读无需登录。查看过往解读会进入 CERCLE 加入／登录预览，以展示未来的会员转化逻辑。

静态版本不会发送或保存门槛表单中的邮箱，不会创建真实账户、真实订阅或跨设备同步；预览权限只持续当前页面访问。阅读、反思、仪式与心愿单仍保存在当前浏览器的 `localStorage` 中。正式上线需接入认证、数据库、邮件服务、独立营销同意、退订与隐私流程。
