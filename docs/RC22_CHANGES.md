# MARÉVYS RC22

Restores the existing original22 major arcana and lunar back, adds56 original minor illustrations, and replaces the78-card grid with a muted midnight rotating deck. Card identity remains unknown until the server reveals the chosen indices. Selection order, reversals and the single clarifier are preserved.

City search now uses a bundled licensed GeoNames gazetteer with multilingual alternate names, region/country labels and trusted IANA zones. No coordinate entry or external API key is needed. Coverage is a2021 cities15000 snapshot rather than every village. Xinjiang results explicitly distinguish Beijing and local-time birth records.

Astrology supports natal and two-person synastry. Two birth charts are computed separately and cross aspects are calculated on the server. If either birth time is unknown, exact cross aspects are withheld. This is synastry, not a midpoint composite chart; there is no fate score or compatibility percentage. Results start with a practical reading and keep chart methods collapsed.

AI guidance answers the exact question first, uses concrete daily-life language and links explanations to verified cards/chart facts. It does not invent the other person's intentions. Saved readings retain the question actually answered even if a new AI question is being drafted.

Interpretation UX references: [Labyrinthos question framing](https://labyrinthos.co/blogs/learn-tarot-with-labyrinthos-academy/how-to-phrase-effective-tarot-card-questions-and-get-the-most-from-your-tarot-reading), [Astro.com city entry](https://www.astro.com/atlas/horoscope), [Cafe Astrology synastry](https://cafeastrology.com/articles/synastry.html). Their content and artwork are not copied. Supplied books are used only for editorial interpretation methodology; Qimen and Thoth-specific card meanings remain excluded from RWS definitions.
